# Coaction 4.0 documentation measurements

Measured on 2026-09-11 on Apple M1 Max, Node 24.16.0. Runtime and benchmark source:
[`12ae616`](https://github.com/coactionjs/coaction/tree/12ae6167b080280ce053f7d8676b7632ce7b7e28).
Dependencies: Coaction 4.0.0, Mutative 1.3.0, alien-signals 3.1.2, Zustand 5.0.11,
Immer 11.1.4. Documentation-only edits made during review do not change these runtime sources.
[Machine-readable results](./4.0-measurements.json) retain every reported case, sample count
and relative margin of error (RME). These are single-machine measurements, not release floors.

## Derived positioning

Reproduce with `pnpm benchmark:zustand-positioning` (`NODE_ENV=production`).
The script imports the local workspace sources. Stable reads use a 1,000-item cart;
update-plus-read cases change one quantity and then read the total. The maintained-field
case updates its total incrementally inside the action. The unrelated scalar cases do
not scan the cart and are reported separately. No React render, transport, history or
remote-sync work is timed. Reselect is not included; these results do not compare its
shared cache against Coaction's.

### Stable reads

| Case                               |     ops/sec |    RME | Samples |
| ---------------------------------- | ----------: | -----: | ------: |
| Coaction cached accessor getter    |  66,109,753 | ±1.67% |      90 |
| Coaction computed with manual deps |  33,809,569 | ±1.27% |      96 |
| Zustand selector recompute         |     787,472 | ±0.13% |      97 |
| Zustand maintained total field     | 112,062,542 | ±0.25% |      96 |

### Update followed by a derived read

| Case                                          |   ops/sec |    RME | Samples |
| --------------------------------------------- | --------: | -----: | ------: |
| Coaction mutable update + cached getter       |    48,480 | ±0.81% |      93 |
| Coaction mutable update + manual deps         |    48,318 | ±0.66% |      92 |
| Coaction object replacement + cached getter   |       169 | ±4.15% |      70 |
| Zustand immutable update + selector recompute |    88,113 | ±0.48% |      97 |
| Zustand immutable update + maintained total   | 2,897,112 | ±0.53% |      95 |

### Unrelated scalar replacement

| Case                                 |    ops/sec |    RME | Samples |
| ------------------------------------ | ---------: | -----: | ------: |
| Coaction unrelated field replacement |  1,598,156 | ±0.14% |      98 |
| Zustand unrelated field replacement  | 21,868,136 | ±0.68% |      93 |

The cached getter is about 84 times as fast as the recomputing selector in the stable
read case. Updating and then reading through a getter reaches about 55% of the Zustand
selector case in this run. Those ratios describe different operations.

## Legacy bulk update suite

Reproduce the timing suite with `pnpm benchmark` (`scripts/benchmark.ts`). This audit
ran an unchanged copy of the benchmark setup and timing code, omitting only the trailing
QuickChart download so that it did not rewrite `benchmark.jpg` or contact that service.

Each case starts with 50,000 objects containing 50 numeric fields each and a 1,000-key
record (not a JavaScript `Map`). Each operation appends to the array and writes a record
entry. The array grows during measurement, so these are not fixed-size leaf updates.
The object-replacement paths and draft paths also have different ownership costs.

| Case                   | ops/sec |     RME | Samples |
| ---------------------- | ------: | ------: | ------: |
| Coaction               |    0.72 |  ±8.93% |       6 |
| Coaction with Mutative |   4,061 | ±21.96% |      86 |
| Zustand                |   5,821 |  ±2.70% |      78 |
| Zustand with Immer     |     277 |  ±0.56% |      89 |

The Mutative row has ±21.96% uncertainty in this run: do not use the smaller gap against
plain Zustand as a stable ranking. All four cases are retained, including Coaction's
expensive object payload. Reading public proxies, detaching incoming containers and
committing them all contribute to that row; it does not isolate one cost or prove that
all of the difference is unavoidable. Use the independent `pnpm benchmark:check` gates
and representative fixed workloads for regression decisions.

## Bundle boundaries

These measurements use the entry-isolation scripts included in `pnpm package:size`:

| Fixture                  |      Gzip |
| ------------------------ | --------: |
| `coaction`               | 10.69 KiB |
| `coaction/shared`        | 14.79 KiB |
| `@coaction/react`        | 13.16 KiB |
| `@coaction/react/shared` | 17.27 KiB |

Core fixtures externalize `alien-signals`, `mutative` and `data-transport`. React fixtures
also externalize React and `use-sync-external-store`. These are retained Coaction code,
not dependency-inclusive application sizes. Fixtures live in
[`scripts/fixtures/core-entry-size`](../../scripts/fixtures/core-entry-size) and
[`scripts/fixtures/react-entry-size`](../../scripts/fixtures/react-entry-size).
Local-entry isolation checks reject reachable shared-runtime markers; declaring
`data-transport` as a package dependency does not mean the default entry bundles it.
